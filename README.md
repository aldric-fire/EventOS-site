# EventOS — public landing page

Public landing page for EventOS, published with GitHub Pages at
https://aldric-fire.github.io/EventOS-site/

This repo holds only the public site: `index.html` + `styles.css`.
No code from the private `eventos` repository, no event data, no API
keys, and no personal information lives here. The personal feed itself
stays private.

## Publish

GitHub Pages is enabled on this repo, publishing from the `main`
branch (root). Push to `main` and the site updates within a few minutes.
